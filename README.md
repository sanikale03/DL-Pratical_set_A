## 🧠 Concepts Covered

### 1. Artificial Neural Network (ANN)
The ANN uses dense layers to learn patterns from structured patient data. The hidden layers use ReLU activation, while the sigmoid output produces a score between 0 and 1 for binary classification.

### 2. OpenCV Image Preprocessing
- **Resize:** standardizes image dimensions to 128 × 128.
- **Grayscale:** converts the image to one intensity channel.
- **Gaussian Blur:** reduces small image noise.
- **Canny Edge Detection:** identifies strong image edges.
- **Contour Detection:** finds boundaries and draws a rectangle around the largest contour.

### 3. Convolutional Neural Network (CNN)
Conv2D layers learn local image patterns, MaxPooling reduces spatial dimensions, Flatten converts feature maps to a vector, and Dense layers produce class predictions.

### 4. Recurrent Neural Network (RNN)
The RNN uses a sequence of 12 monthly passenger counts to predict the following month. The data is split chronologically, without shuffling, to preserve time order.

### 5. Transformer Sentiment Analysis
A pretrained DistilBERT sentiment model classifies text as positive or negative. The selected model does not provide a neutral class, so ambiguous reviews may still be assigned one of those labels.
